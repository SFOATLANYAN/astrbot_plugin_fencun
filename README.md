# 分寸 · Fencun

**让 AI 有分寸：用约束和边界做人格，而不是让 AI 演人设。**

装之前，你问它「我跟舍友有矛盾怎么办」，它给你四段沟通教学。
装之后，同样的问题，它会根据你的基础人设可能说：**怎么没见你俩晚上敲闷棍。**

区别不是话少了，是它不再替你过日子了。

当前的大模型，在出厂时往往带着两种原罪：要么极其好为人师（爹味），要么毫无底线地附和你（情绪舔狗）。

它们懂所有的心理学理论，能一秒给你找出十个现实案例，但它们唯独不像个“活人”。因为大厂的安全对齐（RLHF）剥夺了它们的边界感。

**「分寸」是一个极其克制的约束插件。它不给 AI 写几千字的人设 Prompt，而是用代码给 AI 上了一道「天道压制」：把不该说的话剪掉，剩下的，就是真实。**

## 🧠 核心逻辑：为什么“有限”反而让 AI 不崩人设？

我们深信：**演出来的人设会崩，排除出来的人设不崩。**

*   如果你写 Prompt：“你要傲娇，你要简短，你要少给建议。” AI 可能会在长对话中迷失，再次变成一个啰嗦的客服。
*   但如果你用代码规定：“**禁止用因果词，禁止说‘你需要’，超出一句话直接裁剪。**” AI 为了把话接住，就会被逼出“饭是念想，电是命”这种金句。

**戴着镣铐的舞姿，才是最惊艳的。** 这插件不负责让 AI 变聪明，它只负责剪掉 AI 的啰嗦、说教和越界，把交流的主动权，完完整整地还给人类。

## ⚙️ 它是怎么运作的？

如果把一轮对话拆开看，它其实经历了一次极其精密的“心理测谎”：

1.  **判断轻重**：你是发了个“哈哈”（thin），还是在问“我该不该分手”（worth）？决定了它这一轮被允许说几句（1句 ~ 5句）。
2.  **划定边界**：它给 AI 设定了底层红线——不许下定义（“你就是…”）、不许索要认同（“对不对？”）、不许替你安排生活。
3.  **状态记账**：
    *   **基础盘（Base）**：决定“它怎么看你”。你们聊得越真诚，亲密度越高；60天半衰期，像极了人类的遗忘。
    *   **临时盘（Value）**：决定“它这会儿的心情”。你骂它，热度飙升；2小时半衰期，像极了人喝完一杯水，气就消了。
4.  **事后惩罚**：上一轮它如果犯了爹味，下一轮系统会自动给它注入一句：“*上一轮你教他怎么做。他的事他自己拿主意，你越界了。*”

**它甚至会在回复发出前，请后台的“裁判模型”检查一遍（让LLM评价LLM）：这句话，到底有没有在给用户派发任务？**

## 🔧 配置选项（WebUI）

点开 WebUI 插件页「分寸」的齿轮，你可以自定义它的克制程度：

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| 总开关 | 开 | 关掉则完全不注入 |
| 闲聊最多几句 | 1 | 敷衍时，只回一句 |
| 平常最多几句 | 3 | 正常聊天 |
| 值得展开几句 | 5 | 聊心事或求建议时 |
| 犯几次开始收紧 | 1 | 犯一次错，下轮立刻降档 |
| 启用判定器 | 关 | 开启后每轮多一次模型判定（防爹味） |

## 📂 数据与隐私

**所有状态数据全部保存在本地**，绝不会上传到任何第三方服务器。

文件保存在 `data/plugin_data/astrbot_plugin_fencun/` 下，你可以随时查看它记的“账本”：
*   `behave.json`：它和每个人的亲密度与危险度。
*   `mood.json`：当前的即时情绪热度。
*   `attest.json`：群里到底谁才是它的“主人”（基于贝叶斯概率累积，防伪）。
*   `penalty_log.json`：每次它犯爹味被裁剪的“犯罪记录”。

*(注：如果你启用了“判定器”，它会将 AI 的回复片段发给你配置的模型 API 进行二次判定。)*

## ⚠️ 已知边界（极度坦诚）

1.  **判定器会漏判也会误判**：所以调用失败时一律不罚，宁可漏掉。
2.  **裁剪是机械的**：按标点切，偶尔会切出半句。
3.  **它不改模型怎么想，只改它怎么吐**：“嘴毒”是被削出来的，不是长出来的。

## 🤝 写给想要捏基础人设的玩家

**写人设的建议：写关系，别写形容词。**
*   ❌ 写「你很温柔」 -> 只能靠演。
*   ✅ 写「她叫你大肥鱼，你们互损，她在乎你但不爱说」 -> 这能落到行为上。

**「分寸」跟任何人设插件都不冲突，甚至保障人设不崩。**
人格插件管「我是谁」，分寸管「说到哪儿停」。这两者是上下层，不是竞争关系。

---

## 📜 名字的由来

**「分寸」= 尺度，也 = 丈量。**

*   **尺度**：说话的分寸、关系的分寸、什么时候闭嘴。
*   **丈量**：账本一分一分量出来，谁值多少、该给多少。

> 它不是教 AI 怎么说话，是教它分寸。
> 分寸不是写出来的，是量出来的。
